# Nexus-Player v0.1.0-alpha.1

First public alpha package.

## Included
- Flutter Android application.
- Premium Nexus visual identity.
- Local audio library discovery.
- Rust core and Flutter Rust Bridge.
- Android ARM64 native library packaging.
- Updated launcher icon and application name.

## Compatibility
Android ARM64 (`arm64-v8a`).

## Known limitations
- MPV real playback is not connected.
- MediaSession and lock-screen controls are pending.
- Foreground playback and Bluetooth integration are pending.

Early development build. Not production-ready.
